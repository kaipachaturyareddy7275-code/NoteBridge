
# NoteBridge

A simple platform designed to make note sharing and accessing study materials easier.

## About the Project

NoteBridge is a student-focused project that aims to provide a convenient way to manage and share academic notes.

The project is currently under development.

## Technologies Used

- Python
- FastAPI
- HTML, CSS and JavaScript (planned for frontend development)

## Current Progress

- [x] Initial project setup
- [x] FastAPI backend setup
- [ ] Frontend development
- [ ] Note upload and management
- [ ] Note sharing functionality

## How to Run

1. Clone the repository.
2. Activate your virtual environment.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the backend:

   ```bash
   python -m uvicorn backend.main:app --reload
   ```

5. Open `http://127.0.0.1:8000` in your browser.
